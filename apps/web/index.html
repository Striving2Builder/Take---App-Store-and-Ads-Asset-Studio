      Shape element on this PNG

      Proof element

      Select a proof element to type real numbers and quotes. Empty score paints an em dash — not a made-up App Store rating.

      Type on this PNG

      Type is per store file. None hides kicker/headline on this PNG. Shape and proof elements count against the 6-per-slice element cap, not the strip background.

      Devices on this PNG

      Remove device is allowed only if this PNG still has another element (proof-only). Landscape is this device inside the portrait store file — it does not rotate the ZIP size. Mini screen is a shot thumbnail, not another device.

      Position presets

      Bleed next/prev is one device across two store files (the cut at i·W). Crop top/bottom stay on this slice. Drag still works after a stamp.

      Pitch / yaw

      Sliders on the selected device. Past ~25° the cheap warp can look thin — that is C1, not WebGL.

      Screenshot fit

      Cover crops the screenshot to fill the device screen. Contain shows the whole screenshot, letterboxed if its aspect doesn't match.

      Style & palette

      Lock applies project accent on the canvas only — the app's own accent stays. Use “From scan” when a live palette exists, or Generate for a fresh real palette from the current accent's hue.
